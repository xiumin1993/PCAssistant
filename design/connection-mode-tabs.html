首页 · 连接模式三 Tab（v2）

本轮改动：① 顶部大图标换成连接器（Flutter 用 Icons.cable，两端带插头的线缆，比喇叭更贴合"连接"语义）； ② 删掉"当前模式：xxx"那行文案；③ Tab 自带状态：绿底+✓ = 该模式已连接，红底+! = 该模式上次连接失败； ④ Tab 只表示"在看哪个模式"（选中态用底部深色指示条，与状态色互不干扰）。
状态机（你要的那条规则）
· 切换 Tab 不产生任何连接动作：不断开、不重连、不清状态，绿勾/红! 都留在原来那个 Tab 上。
· 只有在当前 Tab 点「连接」才会：先清除上一个连接状态（断开旧通道）与失败状态，再按该模式的参数发起新连接。
· 连接成功 → 该 Tab 变 ✓ WiFi；连接失败 → 该 Tab 变 ! WiFi 并在副标题写明失败原因； 任一 Tab 变成 ✓ 期间，其它 Tab 显示为普通态。

Flutter 侧图标与配色落点：顶部大图标 Icons.cable（连接态=主色，未连接=outline 灰，失败=红）； Tab 用 SegmentedButton<ConnectionMode>，其 style 按该模式状态三选一： 成功 greenContainer + Icons.check 后缀，失败 redContainer + Icons.priority_high， 无状态用主题默认。selected 只决定"在看哪个模式"，与状态色叠加时绿/红仍可见。
